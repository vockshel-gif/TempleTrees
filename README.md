# Templetrees International: website concept

A clickable prototype of a website for Templetrees International, prepared by Vikum Devinda as a design concept. It is **not** the official Templetrees website.

## Pages
- `index.html`: Home
- `turnaround.html`: Turnaround, one of the four pillars
- `reef-villa.html`: Reef Villa & Spa case study
- `contact.html`: Enquiry form (in this prototype it sends nothing)

## Run it
Open `index.html` in a browser. There is no build step: plain HTML, CSS and JavaScript.

- `assets/style.css`: colours, type and layout
- `assets/site.js`: shared header, menu and footer, the opening loader, and the animations

The text, figures, photographs and logo come from Templetrees International's company profile and remain theirs.
